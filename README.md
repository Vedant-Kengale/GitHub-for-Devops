# 🚀 Git Practice Repository

## 📖 Overview
This repository showcases hands-on implementation of Git version control concepts, covering real-world workflows from basic operations to advanced features. It reflects practical understanding required for collaborative software development.

---

## 🎯 Objectives
- Build strong command over Git fundamentals
- Implement real-world version control workflows
- Understand branching, merging, and rebasing strategies
- Practice efficient code management and tracking

---

## 🛠️ Tech Stack
- Git
- GitHub
- VS Code Terminal

---

## 📂 Key Concepts Covered

### 🔹 Basic Operations
- git init
- git status
- git add
- git commit
- git log

### 🌿 Branching & Collaboration
- Branch creation and deletion
- Branch renaming
- Feature-based workflow
- Merging branches

### 🔄 Advanced Git
- Rebase for clean history
- Reset (soft, mixed, hard)
- Stash (save and restore changes)

### ☁️ Remote Repository
- git remote
- git push
- git pull

---

## ⚙️ Sample Workflow

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <repo-url>
git push -u origin main
